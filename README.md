# NumDrop — After Hours

[Открыть игру](https://tima007.github.io/numdrop/)

Игра о красивых автомобильных номерах: дроп, гараж, биржа, сравнение лотов и клуб коллекционеров.

## Клуб

- **Переговоры:** после выставления лота покупатель может предложить свою цену. Через 30 секунд появляется первое предложение, на ответ отводится 90 секунд. Доступно одно встречное предложение. Превышение бюджета покупателя приводит к отказу; следующий контакт — не раньше двух минут. Продажа только по подтверждению, с обычной комиссией.
- **История цен:** покупки, продажи, цена получения, комиссия и результат сделки. Оценки номеров из гаража записываются раз в минуту при открытой игре. История начинается с обновления; прошлые значения не выдумываются. Хранятся последние 200 операций и до 40 точек для 80 номеров.
- **События:** фиксированное расписание каждые 30 минут и +10% к оценке подходящих номеров. Влияет основная цифровая часть без региона. Шансы дропа и комиссии не меняются; выставленные цены не переписываются.
- **Витрина:** три номера, своё название и три варианта оформления. Проданные номера исчезают из витрины. Витрина сохраняется локально, публичный профиль не создаётся.
- **Контракты:** раз в день каждый из трёх заказов: один любой номер ×1.10, три номера нужной страны ×1.25, два редких номера или выше ×1.35. Избранные и выставленные номера защищены. Применяется обычная комиссия. Обновление в 00:00 по Москве.

## Сохранения

Прогресс хранится в браузере под прежним ключом `numdrop_save_v13`. Старые сохранения совместимы с обновлением. Вход и сетевой рейтинг приостановлены. Файл сайта не содержит сохранений игроков или серверных паролей.

## Размещение

`index.html` содержит приложение, оформление и фотографии. GitHub Pages публикует ветку `main`, корень репозитория. Сборка на сервере не нужна.
